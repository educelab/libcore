# Specification: Mesh Class Redesign

**Track ID:** mesh-redesign_20260320
**Type:** Feature
**Created:** 2026-03-20
**Status:** Draft

## Summary

Extend `Mesh<T, Dims, VertexTraits>` to support composable vertex trait
mixins, per-face normals (lazily computed and cached), a lazy vertex-to-face
adjacency index, and a vertex normal helper function.

## Context

EduceLab Core provides common types for EduceLab C++ projects. The current
`Mesh` class is a simple indexed face set with per-vertex traits. It needs to
become the canonical mesh representation across volume-cartographer and
registration-toolkit, replacing ITK/VTK mesh types without inheriting their
heavyweight dependencies or the manifold constraint of OpenABF's HalfEdgeMesh.

## User Story

As an EduceLab developer, I want a single mesh type that handles geometry,
normals, and adjacency traversal so that I can replace ITK/VTK mesh
dependencies in downstream projects with a lean, dependency-free alternative.

## Acceptance Criteria

- [ ] `traits::WithNormal<T,Dims>` and `traits::WithColor` are added as
      canonical composable trait mixins, combined via multiple inheritance;
      `DefaultVertexTraits` is emptied and Doxygen updated to direct users
      to these mixins
- [ ] `Mesh` provides a lazy vertex-to-face adjacency index built on first
      access, invalidated by any `insertVertex`/`insertFace` call; exposed via
      `vertexFaces(idx)` returning `const std::vector<std::size_t>&`
- [ ] `mesh.faceNormal(idx)` returns a `Vec<T, Dims>` computed lazily from
      the cross product of the face's first two edges (3D only); result is
      cached in a parallel `mutable` vector and invalidated on any
      `insertVertex`/`insertFace` call
- [ ] A free helper `vertexNormal(mesh, idx)` computes and returns an
      angle-weighted average of incident face normals on demand; uses the
      adjacency index and `faceNormal()`; no result caching
- [ ] `Face` remains `std::vector<std::size_t>`; no breaking change to
      existing face construction or comparison call sites
- [ ] All existing `Mesh` tests are updated to reflect the emptied
      `DefaultVertexTraits`; no regressions elsewhere
- [ ] New tests achieve ≥80% coverage of added code
- [ ] All additions are C++17 compatible and header-only

## Dependencies

- Existing `Vec.hpp`, `Color.hpp` (no change required)

## Out of Scope

- UV / texture coordinate support (separate future track)
- Mesh file I/O (OBJ, PLY) — separate future track
- Replacing ITK/VTK in VC or RT directly — downstream work
- HalfEdgeMesh interop (separate future track)
- Upgrading `Face` from `vector<size_t>` to a struct
- Cached vertex normals (computed on demand via helper only)

## Technical Notes

- `faceNormal` cache is a `mutable std::vector<std::optional<Vec<T,Dims>>>`
  parallel to `faces_`; slots are reset to `nullopt` on invalidation (not
  removed) to avoid reallocation on the next access
- `faceNormal` and `vertexNormal` are constrained to Dims == 3 via
  `static_assert`
- I/O functions in a future track will use `if constexpr` + the C++17
  detection idiom (`std::void_t`) to check for `WithNormal`, `WithColor`,
  etc. at compile time and no-op on absent traits
