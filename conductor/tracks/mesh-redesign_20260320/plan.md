building blocks for downstream library trait definitions and for the I/O
detection idiom in a future track.

## Phase 3: Lazy Face Normal Cache

face, cached in a parallel `mutable` vector, invalidated with the adjacency
index on any mutation.

## Phase 4: Vertex Normal Helper

Add a free function `vertexNormal(mesh, idx)` in the `educelab` namespace that
computes an angle-weighted average of incident face normals. No caching.

### Tasks
