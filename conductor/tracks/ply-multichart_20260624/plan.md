## Overview

Follow the project's strict TDD policy: write failing tests against the new
multi-chart PLY behavior first, then implement the writer and reader changes,
then wire up the convenience facade and documentation. The MeshLab convention
(per-texture `comment TextureFile` lines + per-face `texnumber` property) is the
target interchange format. The multi-chart `write_obj` overload and its test are
the reference for both the API shape and the test structure.
